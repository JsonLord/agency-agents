# Donor methodology

Agency integrates donor ideas as deterministic, non-authoritative methods. Evidence analysis returns `analysis_quality`, source diversity, contradiction flags, calibration notes, gaps, and a recommended test. It never returns Nodepad qualification or canonical confidence. Lane analysis selects B2B, B2C, or mixed checks; assumption mapping ranks impact × uncertainty and identifies a kill assumption; pressure testing combines a pre-mortem, devil's advocate case, and discriminating test; pretotyping requires explicit success, failure, and stop criteria.

The harness validates provider provenance and AgentResult structure, rejects forbidden canonical fields, deduplicates stable research inputs, and preserves contradictory evidence. These are execution quality controls, not a venture database.
