# Message Test Cycle Workflow

**Objective**: Test marketing messages to find the most effective communication.

## Steps

1. **Message Design**
   - Agent: Message-Test Designer
   - Output: Set of message variations

2. **Experiment Design**
   - Agent: Experiment Designer
   - Output: A/B test experiment spec

3. **Experiment Execution**
   - Via capability gateway (e.g., browser, social.reddit.publish)
   - Output: Message test results

4. **Evidence Audit**
   - Skill: evidence-audit
   - Output: Audited test results

5. **Message Selection**
   - Agent: Message-Test Designer
   - Output: Winning message and rationale

## Success Criteria

- Messages designed for testing
- A/B test executed and results audited
- Winning message selected with statistical significance

## Output

- Message variations
- Experiment spec
- Test results
- Audited evidence
- Winning message

## Next Steps

Use winning message in marketing and sales efforts.
