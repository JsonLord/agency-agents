# Validate Problem Workflow

**Objective**: Validate that a real problem exists that customers care about.

## Steps

1. **Problem Exploration**
   - Agent: Problem Explorer
   - Output: Initial problem statement

2. **Customer Investigation**
   - Agent: Customer Investigator
   - Output: Customer interviews with problem validation

3. **Ethnographic Research**
   - Agent: Ethnographic Researcher
   - Output: Observational evidence of problem in context

4. **Problem Synthesis**
   - Agent: Problem Explorer (synthesizing)
   - Output: Validated problem with evidence triangulation

## Success Criteria

- Problem validated via multiple methods (interviews, observation)
- Evidence shows customers experience the problem regularly
- Problem is painful enough to motivate action

## Output

- Validated problem statement
- Interview summaries
- Ethnographic notes
- Problem evidence report
