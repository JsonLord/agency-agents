# Customer Discovery Cycle Workflow

**Objective**: Continuously discover and validate customer problems and solutions.

## Steps

1. **Problem Exploration**
   - Agent: Problem Explorer
   - Output: Problem statement

2. **Customer Investigation**
   - Agent: Customer Investigator
   - Output: Customer insights

3. **Assumption Mapping**
   - Skill: assumption-mapping
   - Output: Assumption map

4. **Solution Ideation**
   - Agent: Offer Designer
   - Output: Solution concept

5. **Value Proposition Design**
   - Agent: Value Proposition Designer
   - Output: Value proposition

6. **Experiment Design**
   - Agent: Experiment Designer
   - Output: Experiment spec

7. **Experiment Execution**
   - Via capability gateway
   - Output: Experiment results

8. **Evidence Audit**
   - Skill: evidence-audit
   - Output: Audited evidence

9. **Synthesis and Decision**
   - Agent: Problem Explorer (synthesizing)
   - Output: Updated problem/solution and decision

## Success Criteria

- Cycle completed with evidence-based updates
- Assumptions tested and updated
- Value proposition refined

## Output

- Updated problem statement
- Customer insights
- Assumption map
- Solution concept
- Value proposition
- Experiment spec
- Audited evidence
- Synthesis and decision

## Next Steps

Repeat cycle with new insights.
