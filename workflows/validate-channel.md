# Validate Channel Workflow

**Objective**: Validate that a customer acquisition channel is effective and efficient.

## Steps

1. **Channel Research**
   - Agent: Channel Researcher
   - Output: Channel research report

2. **Distribution Analysis**
   - Skill: distribution-analysis
   - Output: Channel evaluation and recommendation

3. **Channel Experiment Design**
   - Agent: Experiment Designer (for channel tests)
   - Output: Channel test experiment spec

4. **Channel Experiment Execution**
   - Via capability gateway (e.g., outreach.linkedin, social.reddit.publish)
   - Output: Channel test results

5. **Evidence Audit**
   - Skill: evidence-audit
   - Output: Audited channel test evidence

6. **Channel Decision**
   - Agent: Demand Generation Tester
   - Output: Decision to scale, optimize, or abandon channel

## Success Criteria

- Channel evaluated for reach, cost, and effectiveness
- Channel test executed and results audited
- Clear decision based on CAC and conversion metrics

## Output

- Channel research report
- Distribution analysis
- Channel test spec and results
- Audited evidence
- Channel decision

## Next Steps

If channel validated, consider scaling.
If not, test alternative channels.
