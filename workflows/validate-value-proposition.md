# Validate Value Proposition Workflow

**Objective**: Validate that the proposed value proposition resonates with target customers.

## Steps

1. **Value Proposition Design**
   - Agent: Value Proposition Designer
   - Output: Draft value proposition

2. **Customer Language Application**
   - Skill: customer-language
   - Output: Value proposition using customer language

3. **Value Proposition Testing**
   - Agent: Value Proposition Designer (testing)
   - Output: Test results with customer feedback

4. **Positioning Alignment**
   - Agent: Positioning Strategist
   - Output: Positioning statement aligned with value proposition

5. **Message Testing**
   - Agent: Message-Test Designer
   - Output: Message test plan and results

## Success Criteria

- Value proposition tested with target audience
- Resonance score > 4/5
- Clear understanding of what customers value
- Alignment with positioning

## Output

- Validated value proposition
- Customer language version
- Positioning statement
- Message test results
