# Portfolio Review Workflow

**Objective**: Review a portfolio of ventures to allocate resources and make strategic decisions.

## Steps

1. **Venture Data Collection**
   - Agent: Portfolio Allocator
   - Output: Data on all ventures in portfolio

2. **Metrics Calculation**
   - Agent: Portfolio Allocator
   - Output: Key metrics (LTV:CAC, retention, growth, etc.)

3. **Risk Assessment**
   - Agent: Red-Team Analyst
   - Output: Risk assessment for each venture

4. **Opportunity Analysis**
   - Agent: Opportunity Synthesizer
   - Output: Opportunities and synergies across portfolio

5. **Allocation Decision**
   - Agent: Portfolio Allocator
   - Output: Resource allocation decisions

## Success Criteria

- Portfolio data collected and metrics calculated
- Risk assessed for each venture
- Opportunities analyzed
- Allocation decisions made based on evidence

## Output

- Portfolio data
- Metrics report
- Risk assessment
- Opportunity analysis
- Allocation decisions

## Next Steps

Execute allocation decisions and monitor results.
