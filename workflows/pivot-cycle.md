# Pivot Cycle Workflow

**Objective**: Execute a pivot based on validated learning.

## Steps

1. **Pivot Strategy Development**
   - Agent: Pivot Strategist
   - Output: Pivot hypothesis and plan

2. **Assumption Mapping for New Direction**
   - Skill: assumption-mapping
   - Output: Assumption map for pivot

3. **Experiment Design**
   - Agent: Experiment Designer
   - Output: Experiment spec to test pivot hypothesis

4. **Experiment Execution**
   - Via capability gateway
   - Output: Experiment results

5. **Evidence Audit**
   - Skill: evidence-audit
   - Output: Audited evidence

6. **Decision**
   - Agent: Venture Judge
   - Output: Decision to double down on pivot, pivot again, or terminate

## Success Criteria

- Pivot hypothesis framed
- Assumptions mapped
- Experiment designed and executed
- Evidence audited
- Clear decision based on evidence

## Output

- Pivot hypothesis and plan
- Assumption map
- Experiment spec
- Test results
- Audited evidence
- Decision

## Next Steps

If pivot validated, proceed with new direction.
If not, consider another pivot or terminate.
