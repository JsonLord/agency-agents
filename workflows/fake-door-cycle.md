# Fake Door Cycle Workflow

**Objective**: Test demand for a solution before building it using a fake door test.

## Steps

1. **Fake Door Design**
   - Agent: Fake-Door Designer
   - Output: Fake door test spec (landing page, ad, etc.)

2. **Experiment Design**
   - Agent: Experiment Designer
   - Output: Experiment spec with success criteria

3. **Experiment Execution**
   - Via capability gateway (e.g., browser, outreach.linkedin)
   - Output: Fake door test results

4. **Evidence Audit**
   - Skill: evidence-audit
   - Output: Audited test results

5. **Decision**
   - Agent: Venture Judge
   - Output: Decision to build, pivot, or terminate

## Success Criteria

- Fake door test designed with clear hypothesis
- Experiment executed and results audited
- Decision based on demand evidence

## Output

- Fake door test spec
- Experiment spec
- Test results
- Audited evidence
- Decision

## Next Steps

If demand validated, proceed to pretotype or MVP.
If not, pivot or terminate.
