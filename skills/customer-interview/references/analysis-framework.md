# Customer Interview Analysis Framework

## Immediate Post-Interview Steps

1. **Review and Organize** (Within 1 hour)
   - Listen to/watch recording if available
   - Review and expand notes
   - Label each note as fact, quote, observation, or interpretation
   - Highlight verbatim quotes
   - Note emotional reactions and energy levels

2. **Extract Evidence** (Same day)
   - Create a list of direct quotes
   - Note specific behaviors and workarounds mentioned
   - Document context and constraints
   - Separate facts from interpretations
   - Label assumptions that emerged

## Thematic Analysis Process

### Phase 1: Familiarization
- Read through all interview notes multiple times
- Look for patterns, similarities, and differences
- Note initial impressions and surprises

### Phase 2: Coding
- Develop initial codes based on research objectives
- Apply codes to text segments (line-by-line if needed)
- Look for both manifest and latent content
- Keep codes descriptive and focused

### Phase 3: Theme Development
- Group related codes into potential themes
- Review themes against coded extracts
- Refine, combine, or split themes as needed
- Define and name each theme clearly

### Phase 4: Review
- Check if themes work in relation to all extracts
- Create thematic map showing relationships
- Refine specific aspects of each theme

## Evidence Quality Checklist

- [ ] Used primarily direct quotes and observations
- [ ] Separated facts from interpretations
- [ ] Contextualized all findings
- [ ] Noted any contradictions or tensions
- [ ] Considered alternative explanations
- [ ] Documented confidence levels for each finding
- [ ] Traced each insight back to specific evidence

## Common Analysis Pitfalls to Avoid

- Confirmation bias (only seeing what you expected)
- Over-interpretation (reading too much into limited data)
- Under-contextualization (ignoring situational factors)
- False consensus (assuming others think like you)
- Narrative fallacy (creating overly tidy stories)
- Evidence hierarchy errors (treating all evidence equally)

## Synthesis Guidelines

- Look for convergence across multiple sources
- Note divergence and explore reasons
- Focus on patterns, not just individual quotes
- Consider frequency, intensity, and extensiveness
- Distinguish between common and meaningful findings
- Connect insights back to original learning objectives
